# HR 绩效评估 UAT 验收清单（待部署）

本文件是测试清单，不代表测试站已可用。只有独立 HTTPS、真实测试登录、权限检查和部署回读全部通过后，才交给 HR 开始验收。

## 测试边界

- 使用真实 People Hub 页面和登录流程，但只连接独立 UAT 数据库。
- 仅用合成员工、经理和 HR 测试账号。不要输入正式账号密码或真实员工资料。
- 本轮测试不发邮件，不创建真实会议，不调用现有 n8n，也不修改正式 People Hub。
- HR、Admin 和 P0 在绩效评估模块只读。该规则不改正式系统其他模块的角色权限。
- Change profile 只是预览，不是登录。请退出后用另一个测试账号重新登录，验证角色差异。

计划入口：`https://people-hub-uat.srv1866578.hstgr.cloud`。当前状态为未部署，不能作为可用链接转交。

测试账号的领取方式和已核验入口在部署后单独交付。密码不放在本文件、聊天或截图中。

## 工程侧必须另行验证

这些项目不能只靠 HR 看页面证明，也不能用模拟角色代替真实登录：

- 无登录、员工越权、无关经理、跨公司、HR/Admin/P0 写入均拒绝。
- 经理本人作为被评估人时仍只有自评权限。
- 员工收到的原生 HTTP 数据和 Word 没有经理私密字段；经理更改不会改变员工版本或造成员工 CAS 冲突。
- 同时保存只有一个成功；重复操作不重复写入；不确定结果保留草稿并禁止自动重发。
- 等锁期间撤销角色或经理分配后不能继续写入。
- 原生 GoTrue 会话、HTTPS cookies、退出、跨会话持久化和 PostgREST HTTP 409 实测通过。
- API、直接 worker、after 通知、账号管理、找回密码和 Auth 发信均被隔离；不以“没有配置邮件密钥”代替防护。
- 稳定域名、TLS、目标、容器、网络、卷和版本均回读核验；正式站及既有服务保持不变。
